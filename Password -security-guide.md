# Password Power: Student Password-Security Guide

Your password, your power.

## About this guide
This guide supports the Password Power awareness campaign for university students. It explains common account-security risks and practical ways to protect accounts.

## 1. Understand the risks

### Password theft through phishing
Attackers may trick someone into entering a password on a fake sign-in page. Phishing-resistant multifactor authentication can help protect against this type of attack (CISA, 2023).

### Password reuse
Attackers can take advantage of passwords reused across different services. A different password for each account helps prevent one stolen password from putting several accounts at risk (CISA, 2023; 2025).

## 2. Create stronger passwords
CISA recommends passwords that are:
- Long: at least 16 characters.
- Random: not a predictable word or pattern.
- Unique: different for every account.

A passphrase made from unrelated words is another option (CISA, 2025).

## 3. Use a password manager
A password manager can generate, store and fill in passwords. This makes it easier to use a different strong password for every account. Protect the manager with a strong password of its own (CISA, 2025).

## 4. Enable multifactor authentication
Multifactor authentication, or MFA, requires more than one type of evidence to verify your identity when signing in.

It adds protection beyond a password. Where available, choose a phishing-resistant option, such as a FIDO security key (CISA, 2023).

## 5. Take action
Choose one account today:
- Give it a long, random, unique password.
- Store that password in a password manager.
- Enable MFA if the service supports it.

These actions apply CISA's password and account-security recommendations (CISA, 2023; 2025).
