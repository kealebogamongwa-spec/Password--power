# Password Power: Student Security Checklist

Your password, your power.

## How to use this checklist
Review one account at a time. Tick an item only after checking that you have completed it. Do not enter passwords or private account information in this file.

## Password checks
- [ ] My password is at least 16 characters long.
- [ ] My password is random rather than predictable.
- [ ] I use a different password for every account.
- [ ] I use a password manager to generate and store passwords.
- [ ] My password manager has a strong password of its own.

These checks follow CISA's strong-password recommendations (CISA, 2025).

## Extra account protection
- [ ] I have enabled multifactor authentication (MFA), where available.
- [ ] I have selected the strongest MFA option available to me.

MFA adds protection if a password is compromised. CISA recommends using the strongest available option (CISA, n.d.).

## My next action
Choose one unchecked item and work on it next.

Never record your actual passwords, verification codes or recovery codes in this public project.
