## About the project
Password Power is a password-security awareness project for university students. It connects to my cybersecurity awareness brochure.

## Purpose
The project aims to help students understand password-related threats and develop safer account-security habits.

## Planned resources
- A password-security guide explaining threats and protective practices.
- A student account-security checklist.

## How to use the project
Read the guide, then use the checklist to review your account-security habits.
