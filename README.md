# Password Power: Student Security Guide and Checklist

This project contains a short guide and a checklist to help students improve their password security.

## What is included
- `password-security-guide.md`: A short guide explaining strong passwords, unique passwords, password managers and multifactor authentication (MFA).
- `student-security-checklist.md`: A checklist students can use to review the security of their accounts.

## Why this matters
Strong, unique passwords and MFA reduce the risk of someone gaining access to student accounts. CISA recommends using long, random passwords, keeping them unique across accounts, and enabling MFA where available.

## How to use the files
1. Open `password-security-guide.md` to learn the key password-security practices.
2. Open `student-security-checklist.md` and review each account.
3. Tick each checklist item only after completing the action.

## Important note
This project is for educational purposes. Do not enter or store real passwords, verification codes or recovery codes in GitHub.
